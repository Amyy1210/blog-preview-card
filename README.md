# Blog preview card

Hello! This is a solution to the [Blog preview card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS). I tried to make this design match the original as closely as possible.

## Skills that I learned

1. **Flexbox**: Not just using `flex-direction: row`, but also `column` — for example, aligning the author's photo and name in a row.
2. **Hover effects**: When hovering over the headline, the text color changes.
